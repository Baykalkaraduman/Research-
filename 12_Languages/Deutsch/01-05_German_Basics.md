# 🧠 Bölümün Büyük Resmi

İlk beş ders boyunca şu soruların cevabını öğrendik:

- Cümle nasıl kurulur?
- Fiiller nasıl çekimlenir?
- İsimler neden artikel alır?
- "ein" ile "kein" arasındaki fark nedir?
- "sein" fiili nasıl kullanılır?
- Almancadaki bütün temel kişi zamirleri nelerdir?

Bu bölüm, Almancanın temel iskeletini oluşturur.

# 📌 Kişi Zamirleri

| Türkçe | Almanca |
|---------|----------|
| Ben | ich |
| Sen | du |
| O (erkek) | er |
| O (kadın) | sie |
| O (nötr) | es |
| Biz | wir |
| Siz (samimi) | ihr |
| Onlar | sie |
| Siz (resmî) | Sie |

---

# 📌 Düzenli Fiil Çekim Ekleri

| Zamir | Ek |
|--------|-----|
| ich | -e |
| du | -st |
| er / sie / es | -t |
| wir | -en |
| ihr | -t |
| sie / Sie | -en |

## Genel Formül

```
Fiil Kökü + Kişi Eki
```

Örnek:

```
lernen

↓

ich lerne

du lernst

er lernt

wir lernen

ihr lernt

sie lernen
```

---

# 📌 "sein" Fiili

| Zamir | Çekim |
|--------|--------|
| ich | bin |
| du | bist |
| er | ist |
| sie | ist |
| es | ist |
| wir | sind |
| ihr | seid |
| sie | sind |
| Sie | sind |

> **Not:** "sein" düzensiz bir fiildir ve ezberlenmelidir.

---

# 📌 Cümle Yapısı

## Düz Cümle

```
Özne + Çekimli Fiil + ...
```

Örnek:

```
Ich lerne.
```

```
Wir kommen.
```

```
Heute komme ich.
```

> **Kural:** Çekimli fiil her zaman **2. pozisyondadır.**

---

## Soru Cümlesi

```
Çekimli Fiil + Özne + ...
```

Örnek:

```
Lernst du?
```

```
Kommt er heute?
```

> **Kural:** Soru cümlesinde çekimli fiil **1. pozisyondadır.**

---

# 📌 İsimler (Nomen)

## Kural

Almancada bütün isimler büyük harfle yazılır.

Doğru:

```
Buch
Mann
Kind
```

Yanlış:

```
buch
mann
kind
```

---

# 📌 Artikeller

| Artikel | Örnek |
|----------|--------|
| der | der Mann |
| die | die Frau |
| das | das Buch |

> **Altın Kural:** Kelimeleri artikelleriyle birlikte öğren.

Doğru:

```
das Buch
```

Yanlış:

```
Buch
```

---

# 📌 Belirli ve Belirsiz Artikel

## Belirli

```
der Mann

die Frau

das Buch
```

---

## Belirsiz

```
ein Mann

eine Frau

ein Buch
```

### Dönüşüm

```
der → ein

die → eine

das → ein
```

---

# 📌 Olumsuzluk

## kein

Belirsiz artikelin olumsuzudur.

```
ein → kein

eine → keine
```

Örnek:

```
Das ist kein Buch.
```

```
Das ist keine Frau.
```

---

## nicht

Bu seviyede öğrendiğimiz kullanım:

> Fiili veya cümleyi olumsuz yapar.

Örnek:

```
Ich lerne nicht.
```

```
Heute kommt er nicht.
```
