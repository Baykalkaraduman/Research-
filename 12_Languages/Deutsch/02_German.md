# 🇩🇪 Almanca Temelleri - Ders 2
# Konu: İsimler (Nomen) ve Artikellerin Mantığı

> **Amaç:** İsim kavramını anlamak, Almancada neden büyük harfle yazıldığını öğrenmek ve artikellerin mantığını kavramak.

---

# 📚 Önceki Dersten Hatırlatmalar

## Bildiğimiz Zamirler

- ich → ben
- du → sen
- er → o (erkek)

## Bildiğimiz Fiiller

- lernen → öğrenmek
- kommen → gelmek
- gehen → gitmek

## Bildiğimiz Kurallar

### Düz Cümle

Çekimli fiil **2. pozisyondadır.**

```
Ich lerne.
Heute lerne ich.
```

---

### Soru Cümlesi

Çekimli fiil **1. pozisyondadır.**

```
Lernst du?
Kommst du heute?
```

---

### nicht

Şu ana kadar öğrendiğimiz seviyede:

> **nicht**, fiili veya cümleyi olumsuz yapar.

```
Ich lerne nicht.
Heute kommt er nicht.
```

# 📌 Nomen (İsim) Nedir?

İsim; bir varlığı, nesneyi veya kavramı adlandıran kelimedir.

Örnek:

- Mann
- Frau
- Buch
- Kind
- Tisch
- Tür
- Auto

---

# ⭐ En Önemli Kural

## Almancada bütün isimler büyük harfle yazılır.

Doğru:

```
Buch
Mann
Kind
```

Yanlış:

```
buch
mann
kind
```

Fiiller ise küçük harfle yazılır.

```
lernen
kommen
gehen
```

---

# 📌 Artikel Nedir?

Almancada isimler çoğu zaman tek başına kullanılmaz.

İsimlerin önünde küçük bir kelime bulunur.

Bu kelimeye **Artikel** denir.

Örnekler:

```
der Mann
die Frau
das Buch
das Kind
der Tisch
die Tür
das Auto
```

---

# ❗ Çok Önemli

Artikel = biyolojik cinsiyet değildir.

Örneğin:

```
das Buch
```

Kitabın cinsiyeti yoktur.

Yani artikeller, kelimenin **gramatik kimliğidir.**

---

# Öğrenme Kuralımız

Kelimeleri hiçbir zaman tek başına öğrenmeyeceğiz.

Yanlış yöntem:

```
Buch
```

Doğru yöntem:

```
das Buch
```

Aynı şekilde:

```
der Mann
die Frau
das Kind
der Tisch
die Tür
das Auto
```

---

# Bugünkü Formül

```
Artikel + İsim
```

Örnek:

```
der Mann
die Frau
das Buch
das Kind
```

# Öğrendiğimiz Artikeller

| Artikel | Örnek |
|----------|--------|
| der | der Mann, der Tisch |
| die | die Frau, die Tür |
| das | das Buch, das Kind, das Auto |

---

# Mantık

Artikeller, ismin ayrılmaz bir parçasıdır.

Yani zihinde:

❌

```
Buch
```

yerine

✅

```
das Buch
```

şeklinde öğrenilir.

---

# Dikkat

Şu anda artikellerin neden böyle olduğunu öğrenmiyoruz.

Henüz:

- neden der?
- neden die?
- neden das?

sorularını cevaplamıyoruz.

Şimdilik sadece:

> **Her ismin bir artikeli vardır.**

kuralını öğreniyoruz.
