# Konu: Belirsiz Artikel (ein / eine) ve "sein" Fiili

> **Amaç:** Belirli ve belirsiz artikel arasındaki farkı anlamak, "sein" fiilinin ilk çekimlerini öğrenmek ve basit tanımlama cümleleri kurabilmek.

# 📌 Belirli ve Belirsiz Artikel

## Belirli Artikel

Konuşan ve dinleyen hangi nesneden bahsedildiğini bilir.

```
der Mann
die Frau
das Buch
```

---

## Belirsiz Artikel

Bahsedilen kişi veya nesne ilk kez söyleniyorsa ya da hangisi olduğu belli değilse kullanılır.

```
ein Mann
eine Frau
ein Buch
```

---

# İlk Formül

```
der  → ein

die  → eine

das  → ein
```

Örnek:

```
der Mann  → ein Mann
die Frau  → eine Frau
das Buch  → ein Buch
```

---

# Mantık

Türkçedeki:

```
kitap
```

ile

```
bir kitap
```

arasındaki fark gibi düşünülebilir.

```
das Buch
```

↓

```
ein Buch
```

---

# 📌 "kein"

Belirsiz artikelin olumsuzudur.

```
ein → kein

eine → keine
```

Örnek:

```
Das ist ein Buch.

↓

Das ist kein Buch.
```

```
Das ist eine Frau.

↓

Das ist keine Frau.
```

---

# Dikkat

"kein" ile "nicht" aynı görevde değildir.

## kein

İsim grubunu olumsuz yapar.

```
Das ist kein Hund.
Das ist keine Frau.
```

---

## nicht

Şu ana kadar öğrendiğimiz seviyede:

Fiili veya cümlenin ilgili bölümünü olumsuz yapar.

```
Ich lerne nicht.
Heute kommt er nicht.
```

---

# Sonraki Derse Hazırlık

Bir sonraki derste:

- Kişi zamirlerini genişleteceğiz.
- "sie", "es" ve "wir" zamirlerini öğreneceğiz.
- Fiil çekimlerini yeni zamirlere uygulayacağız.

---

# Öğretmenin Notu

Bu derste önemli olan "ein/eine" kalıplarını ezberlemek değildir.

Asıl hedef:

- Belirli ve belirsiz kavramını anlamak.
- "sein" fiiliyle tanımlama cümlesi kurabilmek.
- "kein" ile isimleri olumsuz yapabilmek.

Mantığı anladıktan sonra kurallar çok daha kolay hatırlanacaktır.
