# 🧠 Bu Derste Ne Öğrendim?

Bu derste fiilleri tek tek ezberlemek yerine, onların nasıl oluşturulduğunu öğrendim.

Artık yeni bir düzenli fiil gördüğümde çekimini ezberlemem gerekmiyor.

Önce fiil kökünü buluyor, sonra uygun kişi ekini ekliyorum.

---

# 📖 Yeni Kavram: Fiil Kökü (Stamm)

Bir düzenli fiilin çekimi, fiil kökü üzerine kurulur.

## Kural

```
Mastar

↓

-en kaldır

↓

Kalan kısım = Fiil kökü
```

# 📌 Düzenli Fiil Ekleri

| Zamir | Ek |
|--------|-----|
| ich | -e |
| du | -st |
| er / sie / es | -t |
| wir | -en |
| ihr | -t |
| sie / Sie | -en |

# 📌 Telaffuz Kuralı (Yardımcı "e")

Bazı fiillerde kişi ekini doğrudan eklemek telaffuzu zorlaştırır.

Bu durumda Almanca araya yardımcı bir **e** ekler.

## Genel Mantık

```
Fiil Kökü

+

Tampon e

+

Kişi Eki
```

---

## Örnek

### arbeiten

Yanlış:

```
arbeitst
```

Doğru:

```
arbeitest
```

---

Yanlış:

```
redst
```

Doğru:

```
redest
```

---

### baden

Yanlış:

```
badst
```

Doğru:

```
badest
```

---

# 📌 Şu An İçin Öğrendiğimiz Güvenli Kural

Eğer fiil kökü:

- **d** ile bitiyorsa
- **t** ile bitiyorsa

du ve er/sie/es çekimlerinde yardımcı **e** kullanılır.

Örnekler:

```
reden → redest, redet

arbeiten → arbeitest, arbeitet

baden → badest, badet

warten → wartest, wartet
```

---

# 📌 Sonu "s" ile Biten Fiiller

Örneğin:

```
reisen
```

Fiil kökü:

```
reis
```

Normal formül:

```
reis + st
```

Yazımda iki **s** yan yana kullanılmaz.

Bu nedenle:

```
reist
```

şeklinde yazılır.

> Bu, yazım ve ses uyumuyla ilgilidir. İlerleyen derslerde daha ayrıntılı incelenecektir.

# 🧠 Öğrenme Psikolojisi

Bu derste artık fiilleri ezberlememeyi öğrendim.

Yeni bir fiil gördüğümde şu yolu izliyorum:

1. Mastarı bul.
2. "-en" ekini kaldır.
3. Fiil kökünü elde et.
4. Gerekliyse yardımcı "e" ekle.
5. Kişi ekini ekle.

---

# 🏆 Ders Sonu Özeti

Bu derste öğrendiklerim:

- Fiil kökü (Stamm)
- Mastardan kök bulma
- Düzenli fiil çekim mantığı
- Yardımcı "e" kuralı
- Sonu "s" ile biten köklerde yazım mantığı
- Ezber yerine üretim yöntemi

---

# 💡 Altın Kural

> **Yeni bir düzenli fiil öğrendiğimde yalnızca mastarını öğrenmem yeterlidir.**

Çünkü çekimini artık kuralları kullanarak kendim oluşturabilirim.
