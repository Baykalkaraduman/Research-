# 📖 Yeni Zamirler

| Almanca | Türkçe |

---

# ⚠️ Dikkat

Almancada üç farklı "sie" vardır.

| Yazılışı | Anlamı |
|----------|---------|
| sie | o (kadın) |
| sie | onlar |
| Sie | siz (resmî) |

> Cümle başında yazıldığında hem **sie** hem de **Sie** büyük harfle başlayacağı için anlamı bağlam belirler.

Örneğin:

```
Sie kommen.
```

şu iki anlama da gelebilir:

- Onlar geliyor.
- Siz (resmî) geliyorsunuz.

# 🧠 Düzenli Fiillerin Genel Formülü

Artık bütün temel kişi eklerini biliyoruz.

| Zamir | Ek |
|--------|-----|
| ich | -e |
| du | -st |
| er / sie / es | -t |
| wir | -en |
| ihr | -t |
| sie / Sie | -en |

Bu tablo, düzenli fiillerin temel çekim sistemidir.

---

# 📌 sein Fiilinin Formülü

```
ich → bin

du → bist

er / sie / es → ist

wir → sind

ihr → seid

sie / Sie → sind
```

# 📌 Dikkat Edilecekler

## 1.

```
ihr
```

"siz" anlamındadır ancak yalnızca samimi konuşmalarda kullanılır.

---

## 2.

```
Sie
```

resmî hitaptır ve her zaman büyük harfle yazılır.

---

## 3.

```
sie
```

hem "o (kadın)" hem de "onlar" anlamına gelebilir.

Anlamı cümlenin bağlamından anlaşılır.

---

## 4.

```
sein
```

fiili düzensizdir.

Özellikle şu çekim ezberlenmelidir:

```
ihr → seid
```

# 🎯 Ders Sonu Özeti

Bu derste öğrendiklerim:

- ihr zamiri
- sie (onlar)
- Sie (resmî siz)
- Düzenli fiillerin tam kişi çekimi
- sein fiilinin temel tam çekimi
- "sie" ve "Sie" arasındaki fark
- Düzenli fiillerde ortak çekim örüntüleri

---

# 🧠 Öğrenme Psikolojisi

## Bu derste beynim ne öğrendi?

✅ Temel kişi zamirleri tamamlandı.

✅ Düzenli fiiller artık bütün temel zamirlerle çekilebiliyor.

✅ Yeni bir düzenli fiil öğrenildiğinde aynı çekim sistemi uygulanacak.

---

## Bu neden önemli?

Artık Almancadaki temel fiil çekim sistemi tamamlandı.

Bundan sonra öğrenilecek her düzenli fiil, aynı örüntüyle çekilecektir.

# 🚀 Sonraki Derse Hazırlık

Bir sonraki derste:

- Düzenli fiillerin yapısını daha derin inceleyeceğiz.
- Fiil kökü (Stamm) kavramını öğreneceğiz.
- Düzenli fiiller neden bu şekilde çekimleniyor, mantığını göreceğiz.

---

# 💡 Altın Kural (Ders 5)

> **Yeni bir düzenli fiil öğrendiğinde, yalnızca mastarını bilmen yeterlidir.**

Çünkü kişi eklerinin tamamını artık biliyorsun.

Örneğin:

```
lernen
```

yerine

```
arbeiten
```

öğrendiğinde aynı çekim sistemini uygularsın.
